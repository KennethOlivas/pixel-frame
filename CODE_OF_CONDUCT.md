# Código de conducta

Nos comprometemos a mantener una comunidad respetuosa, inclusiva y enfocada en el producto. No se toleran acoso, insultos, discriminación ni la publicación de contenido privado sin permiso.

Si observas una conducta que contradiga estas normas, informa de ella de forma privada a [KennethOlivas](https://github.com/KennethOlivas). Todas las comunicaciones se tratarán con discreción. Las respuestas pueden incluir una advertencia, la eliminación de contenido o la restricción de participación.
