# Política de seguridad

No abras un issue público para una vulnerabilidad que pueda afectar archivos locales, aislamiento del navegador o dependencias. Repórtala de forma privada mediante [GitHub Security Advisories](https://github.com/KennethOlivas/pixel-frame/security/advisories/new).

Incluye pasos de reproducción, versión del navegador, versión de PixelFrame y el impacto esperado. Se confirmará la recepción y se coordinará una corrección antes de divulgar los detalles.
